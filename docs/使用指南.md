# 丸物设计室：第一阶段使用指南

这是一个中文、以本地文件为主的日式扭蛋海报编辑器。基于 ikuaitu/vue-fabric-editor 和原有 Fabric.js 图片、文字、对象变换及渲染能力，保留原 MIT 许可证。默认首页为新工作台，上游编辑器源码仍保留。

## 在自己的电脑打开

云端目前没有提供能从你的电脑访问的公开预览。云端的 localhost 不是可访问的演示链接。

先将**本次修改后的代码**下载或检出到电脑，安装 Node.js **20.20.2**（项目兼容范围为 Node 18–20）。不要用系统预装的 Node 24 或 pnpm 11。打开代码目录中的终端，依次执行：

```sh
npm install -g pnpm@8.4.0
pnpm install --frozen-lockfile
pnpm dev --strictPort
```

保持最后一个终端窗口运行，然后在**同一台电脑的浏览器**地址栏输入 `http://127.0.0.1:3000/`。这是本地启动地址，不是云端预览链接。停止服务时，在终端按 Ctrl+C。

安装使用官方 npm 源，Canvas 原生二进制从 GitHub 官方发布下载。初次安装需要这些网站的网络访问；安装完成后，本阶段编辑流程不需要在线素材服务。项目含原生 Canvas 依赖，在 GitHub 没有对应操作系统/架构的预编译包时，可能需要该系统的 Canvas 编译依赖。本次验证平台为 Linux x64 + Chromium；未声称已测试所有 Windows/macOS 组合。

## 从模板制作一张海报

1. 左侧点击「模板」，选择 3、4、5 或 6 款版式。模板会成为一个新页面，不覆盖旧页面。
2. 点击「产品图」→「上传产品图」，选择透明 PNG、JPEG 或 WebP。上传只加入共享资产库；点击缩略图才加入画布。
3. 在画布或右侧图层中选中「产品位」，在某张产品图下面点击「替换选中」。图片等比放入原位置并保留旋转角度；需要时可再次替换。
4. 直接拖动图片调整位置，拖动角点等比缩放，拖动顶部旋转控制点调整角度。也可用右侧「旋转角度」输入数字。
5. 点击「文字」→「文字工具」，在画布任意位置点击添加文字。双击文字可直接输入；右侧调整字体、字号、颜色、描边、阴影、行距和字距。
6. 右侧图层按从上到下显示覆盖关系。拖动 **☷** 排序；修改名称即可重命名；「◉/○」切换显示；「开/锁」切换锁定；「×」删除对象。
7. 完成后点击「导出 PNG」。底部可选 1×、2×、3×；900×1200 画布默认 2× 导出为 1800×2400。导出不会包含选框或编辑辅助元素。

模板中的产品位、款式名称、标题、边框、圆章及小字都是独立对象，可以选择、删除、改色和替换。模板不包含第三方商品图片。

## 多页、保存与迁移

- 底部「新页面」「复制页」创建页面，点击页签切换；每页尺寸、背景、对象布局独立。
- 所有页面共享同一资产库。删除画布对象或页面**不会删除原始图片**。
- 修改后自动保存到当前浏览器的 IndexedDB，顶部显示保存状态；也可点击「保存」。等到「已自动保存到本机」再关闭或刷新。
- 自动保存仅在**相同浏览器、相同地址与端口**下恢复；无痕模式、清除网站数据、换浏览器或换端口不会共享数据。
- 「导出项目」保存 `.gashapon.json` 文件，包含全部页面和嵌入的 PNG/JPEG/WebP 资产。它与 PNG 图片不同，是后续继续编辑的完整工程。
- 「导入项目」选择完整项目文件并确认替换当前项目。替换前请先导出当前项目备份。页面图片会随文件一起恢复，不需要原上传文件。
- 若浏览器存储空间不足，顶部会明确显示保存失败，请立即导出项目备份。不要把浏览器自动保存作为唯一备份。
- 撤销/重做针对当前页当前会话，刷新或重新导入后重新开始记录；导入与删除页面属于需确认的项目操作，不能通过单页撤销找回。

快捷键：Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做，Ctrl/⌘+D 复制，Ctrl/⌘+S 保存，Delete 删除，Esc 退出文字工具。文字输入时保留原生编辑快捷键。

## 素材与 AI

「素材」中可上传本地装饰，或添加可编辑圆形、标签。上游 `github.kuaitu.cc` 返回不可用页面，因此首页不向它请求数据，并显示「在线素材暂不可用」。这不影响本地图片、文字、页面、保存及导出。

「AI 找素材」明确显示**尚未接入**。接口边界保存在 `src/gashapon/ai.ts`：自然语言输入 → 中英日关键词扩展 → 真实检索（含来源与授权信息）→ 视觉筛选。第一阶段没有生成假搜索结果，也不要求填写 API 密钥。

## 当前限制

- 面向桌面浏览器，建议窗口至少 1280px 宽。小屏可横向滚动，未提供手机专用布局。
- 最多 30 页、200 张共享图片；单张最多 20MB / 4000 万像素，项目图片编码总量最多 100MB。
- 画布单边 100–4096px，总计不超过 1600 万像素；单次 PNG 导出最多 3200 万像素。
- 系统字体在不同电脑上可能不同；项目提供两款上游已有内置字体，切换时会等待字体加载。未实现自定义字体文件导入。
- 项目只导入本编辑器格式及安全的栅格资产，不支持任意上游 JSON、SVG、PSD 或网页图片 URL。
- 上游历史依赖仍有审计告警，开发服务器仅用于本机开发，不应直接暴露到公网；详见验收记录。
