# 第二阶段：真实素材检索与 AI 分析

当前按用户选择：不配置 OpenAI、不进行付费调用，默认使用免费关键词检索。

第一阶段的图片、文字、图层、多页、自动保存和完整项目格式保持兼容。新增功能位于左侧「AI 找素材」，素材加入原来的共享资产库。

## 先说明当前接通程度

- **已实测成功：Wikimedia Commons 官方直连**。真实检索、图片预览、授权展示、加入资产库、放入画布、项目导出和刷新恢复，均通过无模拟数据的浏览器验收。
- **已评估但当前不可用：Openverse 匿名 API**。本次从云端收到 HTTP 403 / Cloudflare 验证页，不是有效 API 数据。因此保留独立入口及明确错误，未把 Wikimedia 直连结果冒充 Openverse。
- **OpenAI 文字与图片分析：已实现服务端调用，缺少实际密钥，尚未完成付费调用实测**。接口、结构校验、筛选和错误处理已通过模拟接口的自动测试；这些测试不等于真实 AI 调用成功。未配置时自然语言搜索按钮禁用，显示清楚的配置说明。
- 没有接入 SearXNG 或更多图库；当前先验证这一条实际素材来源。

## 服务、费用与配置名称

| 服务 | 用途 | 费用类型 | 配置 |
| --- | --- | --- | --- |
| Wikimedia Commons 官方 API | 首个已验证的真实素材检索入口 | 免费公开接口，受站点频率及使用政策限制 | 不需要密钥 |
| Openverse API | 已实现适配器，当前访问受限 | 匿名接口通常免费且限流；本版本未接入 OAuth | 不需要在本版本填写 Openverse 密钥 |
| OpenAI API | 需求提取、中英日关键词、候选图片分析 | 按模型的输入/输出及图片用量收费；与 ChatGPT 订阅独立 | `POSTER_AI_KEY`（密钥）、`POSTER_AI_MODEL`（默认 `gpt-4.1-mini`）、`POSTER_AI_VISUAL`（默认 true） |
| 本机 Node 服务 | 保管密钥、调用外部 API、验证图片和导入 | 本机运行，无额外服务器订阅 | 默认仅监听 `127.0.0.1:3001` |

一次自然语言检索最多 1 次文字分析、1 次最多含 6 张图的视觉分析，每次 AI 响应上限 1600 tokens；补充要求会再次调用。实际金额取决于所选模型、输入及输出，未固定承诺费用。请在 OpenAI 账户中设置你能接受的预算/额度。

## Mac 更新与启动

1. 先在旧编辑器中「导出项目」做备份，保留原下载文件夹。
2. 下载第二阶段分支 `feat/ai-material-search` 的代码并解压。终端进入**新文件夹**。不要覆盖旧文件夹中的个人配置。
3. 在旧服务的终端按 Ctrl+C 停止，然后在新文件夹执行：

```sh
"$HOME/.local/bin/pnpm" install --frozen-lockfile
"$HOME/.local/bin/pnpm" dev --strictPort
```

命令会同时启动素材服务和 Vite 前端，不需要再手动开第二个终端跑服务端。两个端口分别为 3001 / 3000；被占用会明确报错，不会停止别人的进程。

保持终端打开，在同一台 Mac 的 Safari 中打开 `http://127.0.0.1:3000/`。这不是云端公共预览。相同浏览器和地址可继续恢复第一阶段的本机项目；若未恢复，使用备份文件导入。

## 不付费也能先试的真实流程

1. 左侧点击「AI 找素材」。
2. 选择「关键词直接搜索」，入口为「Wikimedia 官方直连」。
3. 输入短词，例如 `flower` 或 `cherry blossom`，点击「搜索真实素材（不调用 AI）」。
4. 候选卡片显示真实图片、作者、来源页面、授权条款、署名信息，以及明确的「未进行图片分析」标记。
5. 打开来源和授权核对，勾选授权确认后点击「加入共享素材库」。
6. 界面切换到「素材」，点击图片缩略图即可放入画布。该图片可在所有页面使用，删除画布对象不删除原资产。
7. 保存与刷新，或导出完整项目再导入，图片及来源、作者、授权、署名信息都会保留。

关键词模式不会假装提取中文需求、生成三语词或完成图片分析；这里的“推荐理由”只是实际检索依据，明确标为未分析。

## 安全配置 OpenAI

**不要把密钥发到聊天、写进 Vue 文件、APP_ / VITE_ 变量，或提交到 GitHub。**

在新项目的终端运行：

```sh
"$HOME/.local/bin/pnpm" ai:configure
```

- 模型名称直接按回车，使用 `gpt-4.1-mini`；如改成其他模型，需要该模型支持图片与结构化 JSON 输出。
- 在提示后粘贴 API 密钥再按回车。**输入不会显示在终端上，这是正常的。** 空输入取消并保留原配置。
- 文件保存到 `server/.env.local`，权限为 600（仅当前用户读写），使用私有临时文件原子替换，临时文件也被 Git 忽略。
- 停止并重新运行开发服务后，网页点击「刷新配置状态」。只显示是否已配置，不返回密钥。显示“已配置”说明读到了值，不代表已经通过 OpenAI 认证；实际请求失败会明确报错。
- 如用云环境，在环境设置的安全密钥入口填写 `POSTER_AI_KEY`，目标域名 `api.openai.com`；运行环境变量优先于本机文件。不要把密钥值写进安装脚本。

配置命令的隐藏输入、600 权限、正确读取和 Git 忽略已实测；验收使用的是一次性假凭据测试输入，未向 OpenAI 发出调用，测试文件随后删除。仓库不包含实际凭据。

## 使用自然语言及补充要求

配置好后切换「自然语言 + AI」，例如：

> 日式复古扭蛋海报用的樱花装饰，奶油粉与米色，不要人物。

点击「分析并检索（调用 AI）」。服务端先提取风格、颜色、类型、排除项、透明要求，展示中英日关键词，再请求所选真实索引、下载候选图片，并通过服务端调用 OpenAI 图片分析。界面只展示完成分析且被判为匹配的候选；图片无法获取、分析失败或输出格式不合法时不假定符合要求。

可以点击「更复古」「不要人物」「只要透明素材」，也可输入补充要求。原需求和按顺序追加的要求一起发给服务端，保留未被撤销的条件，最新明确条件优先。最多 10 条补充要求；原需求改写后需重新检索。补充操作同样会产生 AI 费用。

“只要透明素材”额外校验 PNG 的实际 alpha 像素，不把白底 PNG 或 AI 声称透明的照片算作透明素材。目前严格透明筛选只支持真实带透明像素的 PNG，未把 WebP 仅凭格式推断为透明。无符合结果时显示空结果和原因。

AI 是对真实候选的辅助筛选，不保证语义判断绝对正确；最终图片与授权仍由用户查看选择。取消等待会停止前端接收，已经发出的外部调用可能仍计费，不要连续重复提交。

## 图片来源、授权和导出

默认仅接受 CC0、PDM、BY 和 BY-SA 的可导入栅格图片，排除 NC、ND 或不能识别的授权。BY / BY-SA 需要署名；BY-SA 的改编作品还需遵守相同方式共享等条款。请核对来源原页，索引元数据不等于独立的权利担保。

资产库提供「来源与署名」链接，完整项目保留原图、来源、作者、授权链接和署名文本。导出的 PNG **不会自动把署名印在画面上**，请按来源要求在海报或发布说明中署名。图片不会在未选择时自动加入项目。

## 开发与安全边界

- 前端只访问同源 `/api/material-search/*`，OpenAI 密钥从不返回前端。图片分析用服务端下载的实际图片，不把任意客户端 URL 传给模型或下载器。
- 素材下载仅允许固定的官方 API / Wikimedia / Flickr 图片域名；逐次校验重定向，拒绝本机、内网、带密码 URL、SVG 和伪图片。导入必须携带近期真实搜索产生的 token，不能把导入接口当作任意 URL 代理。
- 单图下载上限 8MB，透明 PNG 检测上限 1600 万像素；视觉分析最多 6 张、每张预览最多 1MB。过大或不可读取的图会明确排除或报错。
- 同源与本机 Host/Origin 校验、请求大小及频率限制、过期缓存均在服务端执行。搜索和导入错误不清空当前画布。
- 两个新增依赖固定版本：`https-proxy-agent@7.0.6`（支持代理环境），`pngjs@7.0.0`（纯 JS alpha 检测）。没有批量升级旧依赖或增加新的原生编译依赖。
- 原有依赖安全审计及全仓库类型检查的历史问题仍见第一阶段验收，新工作台类型检查单独执行。
- 本版本支持本机开发启动；仅上传静态 dist 文件不会自动部署服务端。生产托管、登录与多人服务不在本阶段范围，不能直接将开发服务暴露到公网。

验证命令与真实结果见 [第二阶段验收](第二阶段验收.md)。
